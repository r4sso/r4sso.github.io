Configure Flameshot with Sway

21 April 2026 / 1 min read
Categories Guides
Tags linux sway wayland

# Introduction

Flameshot is a powerful and simple-to-use screenshot tool. You can use it on Windows, macOS and Linux. I have been using it in college for my assignments since it has tons of drawing tools. You can just copy and paste without manually editing the screenshot files.

# Installation

Install Flameshot and Grim:

doas apk add flameshot grim

# Configuration

Configure Flameshot to use Grim since we are on Wayland.

~/.config/flameshot/flameshot.ini

[General]
disabledTrayIcon=true
useGrimAdapter=true
disabledGrimWarning=true

Set Sway to use Flameshot when the Print key is pressed. Add the following to your Sway config:

~/.config/sway/config

## Required for copy to clipboard to work.
exec /usr/bin/flameshot

## Screenshot
bindsym Print exec flameshot gui
